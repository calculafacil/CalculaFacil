CALCULAFÁCIL POLÍTICA DE PRIVACIDAD

> TU_PRIVACIDAD_PRIMERO

En CalculaFácil creemos que no necesitas regalar tus datos para usar una calculadora. Esta página explica, en lenguaje claro, qué información tratamos y qué no.

Qué datos NO recogemos

  • Sin registro: no pedimos nombre, correo ni ningún dato personal para usar las calculadoras.
  • Sin formularios: aquí no hay nada que rellenar más allá de los números de tus cálculos.
  • Tus cálculos no se envían a ningún servidor: todas las operaciones se ejecutan dentro de tu propio navegador.

Qué se guarda en tu navegador

Para que la web te resulte cómoda, guardamos dos cosas usando el almacenamiento local (localStorage) de tu propio dispositivo:

  • Tu historial de cálculos: puedes vaciarlo cuando quieras con el botón "Vaciar historial" de cada calculadora.
  • Tu tema de color preferido: para que la web luzca como te gusta cada vez que vuelvas.

Esta información nunca sale de tu dispositivo: no la vemos, no la compartimos y desaparece si borras los datos de navegación del navegador.

Análisis anónimo y cookies

Usamos Google Analytics (a través de Google Tag Manager) para conocer, de forma agregada y anónima, cuántas personas visitan la web y qué calculadoras son más útiles. Estos datos no nos permiten identificarte personalmente. Puedes bloquear esta analítica con cualquier extensión de bloqueo o desactivando las cookies en tu navegador: las calculadoras funcionarán igual de bien sin ella.

Alojamiento y terceros

La web está alojada en GitHub Pages, cuyo proveedor puede registrar datos técnicos estándar (como la dirección IP o el tipo de navegador) según sus propias políticas. No utilizamos publicidad en este momento; si esto cambia algún día, actualizaremos esta página y lo indicaremos claramente.

Tus derechos y contacto

Si tienes dudas sobre esta política, quieres ejercer algún derecho o simplemente preguntar algo, escríbenos a:

calculafacil.web@gmail.com
